Ro-Brew-To: Autonomous Coffee Making Robot

Expected July 2026
ROS 2 Jazzy Gazebo Harmonic MoveIt 2 OpenCV

A full perception to action pipeline for a UR3e 6-DOF manipulator with Robotiq 2F-85 gripper. The robot detects objects via vision, estimates their 6D pose, plans collision free trajectories using both RRTconnect and computeCartesianPath and executes a complete coffee brewing sequence autonomously in simulation.

Demo video coming soon
  • Built a marker based 6D pose estimation pipeline using OpenCV ArUco detection, computing object position and orientation by projecting pixel coordinates to world frame through camera intrinsics and TF2 transform chains
  • Designed a custom Gazebo Harmonic simulation environment with an overhead RGBD camera sensor (800×600, 80° FOV), articulated coffee machine model, and calibrated sensor plugins for realistic perception input
  • Developed collision aware motion planning using MoveIt 2 with OMPL, including Cartesian arc trajectories for lever actuation and constrained planning for precise pod insertion into the machine
  • Architected the full ROS 2 node graph connecting perception (camera → detection → pose estimation) to planning (MoveIt 2) to execution (ros2_control → Gazebo physics), targeting closed loop autonomy from raw image to brew completion
  • Resolved critical integration issues including a camera sensor race condition under llvmpipe software rendering, gripper controller action name mismatches, and SRDF self collision false positives

DA-PF: Degradation-Aware Particle Filter for Robot Localization

January 2026 – April 2026
ROS 2 Jazzy Gazebo Harmonic Particle Filter Sensor Fusion

A multi sensor particle filter that continuously estimates per sensor reliability and dynamically scales each modality's contribution to the likelihood function, enabling robust localization under progressive sensor degradation where standard approaches like Nav2 AMCL fail. In the video below the first terminal displays the confidence monitor of camera and ultrasonic.

  • Designed a confidence scaled likelihood update (wi = Lcamαcam × Lultαult, α ∈ [0, 1]) that continuously modulates each sensor's contribution to particle weights, replacing hard threshold switching with smooth graceful degradation
  • Fused three perception modalities, monocular RGB camera (ArUco 6D landmark detection, 800×600, 15 Hz), HC-SR04 ultrasonic (0.02–4.0 m range, 10 Hz), and IMU (100 Hz) through a dedicated Confidence Monitor Node publishing real time per sensor reliability estimates
  • Implemented runtime sensor degradation gazebo simulation Gaussian blur with contrast attenuation on camera frames to model fog induced visibility loss, and Gaussian noise injection with stochastic max range dropout on ultrasonic readings to simulate acoustic interference across 4 experimental conditions
  • Built a 20 m × 15 m Gazebo Harmonic warehouse with 16 ArUco fiducial markers and independently degraded LiDAR scans for the Nav2 AMCL baseline, ensuring controlled and fair evaluation
  • Achieved 1 m improvement in Absolute Trajectory Error (ATE RMSE) over Nav2 AMCL under simultaneous multi sensor failure, with open source evaluation scripts for full reproducibility

Control Barrier Function for Safe Robot Navigation

September 2025 – December 2025
Gazebo CBF Multi-Robot Safety-Critical Control

Safety guaranteed multi robot navigation in cluttered warehouse environments using Control Barrier Functions enforcing real time collision avoidance as a hard constraint while minimally deviating from the nominal controller's intent. In the video below two robots reach there respective goals while they pass through a common path and the CBF kicks in for them to not collide.

  • Formulated CBF based safety constraints as a quadratic program (QP) that filters nominal velocity commands in real time, computing the minimum deviation safe control input at each timestep while guaranteeing forward invariance of the safe set
  • Integrated LiDAR based obstacle detection to construct CBF barrier functions from real time range measurements, creating distance dependent safety boundaries around static obstacles and dynamic agents
  • Validated the approach across multi robot simulation scenarios in warehouse layout simulation in gazebo with intersecting paths, demonstrating zero collision performance with minimal trajectory deviation from nominal paths
